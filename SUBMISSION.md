# HH Goa 2026 submission kit

## Product

**Unspool — Speak. Sort. Start.**

People often know what they need to do but struggle to turn a noisy collection of thoughts into a first action. Unspool gives those thoughts somewhere to land. Dictate through Wispr Flow, organize the text into editable steps, and focus on one task.

The design intentionally reduces choices: capture, review, act. Local processing keeps tasks on the device and avoids API-key setup during the demo. Original wording remains available in the task editor, so suggestions can be checked.

## Voice prompt sequence for a genuine recorded build

These are prompts to dictate during a real build, not a script for pretending an existing build was voice-created.

1. “Build Unspool, a calm web app that turns my dictated brain dump into an editable task plan. Use a sage sidebar, warm paper panels, lime buttons, and a capture, review, focus layout. Make it run without API keys.”
2. “Split my sentences into tasks. Suggest urgency, duration, and today or tomorrow dates. Keep the original thought visible when I edit a task. Explain that this is rule-based organization.”
3. “Add task editing, completion, search, a focus timer, local saving, undo, Markdown export, and validated JSON backups. Make it work on a phone too.”
4. “Test month-end dates, invalid backups, duplicate tasks, and long inputs. Preserve my draft if organization fails. Report anything you could not test.”
5. Dictate a real improvement based on what you observe. For example: “Add a ten-minute quick-win filter.” Let the assistant implement and test it while recording.

## 90-second product demo

**0–15 seconds — problem:** “A busy mind doesn't need another complicated dashboard. It needs somewhere to put the mess, and one small place to start. This is Unspool.”

**15–35 seconds — capture:** Show Flow active and dictate into the capture box: “I need to finish the pitch today, urgent, thirty minutes. Book a train tomorrow, ten minutes. Maybe explore a new logo idea, twenty minutes.” Check how Flow transcribes number words. If the transcript retains spelled-out numbers, edit the numeric durations in the task editor or dictate numeric forms; the organizer currently parses digits.

**35–55 seconds — review:** Click “Untangle my thoughts.” Show the task list. Open the pitch task, inspect the original wording, change its duration, and save.

**55–75 seconds — action:** Click “Let's focus.” Start, pause, and reset the timer. Complete the task, then show the Done filter and progress ring.

**75–90 seconds — close:** Export the plan. “Speak it. Sort it. Start it. Less in your head, more in your day.”
